# Word Ladder

> [!TIP]
> **🧠 Memory hook**
> Words are stepping stones; you may jump to another word only if one letter changes.
> **Mantra: BFS; NEIGHBOUR = ONE LETTER CHANGED AND IN THE LIST**

**Animation:** [▶ Open in browser](https://d9-cell.github.io/java-brain/Graph/Grid%20and%20BFS/Grid%20and%20BFS%20Animations.html#p=18) · **Pattern hub:** [Grid and BFS - Pattern Map](Grid%20and%20BFS%20-%20Pattern%20Map.md)

## Problem
Return the number of words in the shortest transformation from beginWord to endWord, changing one letter at a time through words of the list.

## Key insight
BFS on the implicit word graph: generate neighbours by replacing each position with a–z and keeping those in the dictionary. Bidirectional BFS meets in the middle and is much faster on large lists.

## Approach 1: BFS
```java
// BFS where each word links to every word one letter away; the neighbours are generated by swapping one letter
public int ladderLength(String beginWord, String endWord, List<String> wordList) {
    Set<String> words = new HashSet<>(wordList);
    if (!words.contains(endWord)) return 0;
    Queue<String> que = new ArrayDeque<>(List.of(beginWord));
    Set<String> visited = new HashSet<>(List.of(beginWord));
    int length = 1;
    while (!que.isEmpty()) {
        for (int size = que.size(); size > 0; size--) {
            String cur = que.poll();
            if (cur.equals(endWord)) return length;
            char[] c = cur.toCharArray();
            for (int i = 0; i < c.length; i++) {
                char old = c[i];
                for (char ch = 'a'; ch <= 'z'; ch++) {
                    c[i] = ch;
                    String next = new String(c);
                    if (words.contains(next) && visited.add(next)) que.add(next);
                }
                c[i] = old;
            }
        }
        length++;
    }
    return 0;
}
```

## Approach 2: Bidirectional BFS
```java
// Bidirectional BFS: always expand the smaller frontier, stop when they touch
public int ladderLengthBidirectional(String beginWord, String endWord, List<String> wordList) {
    Set<String> words = new HashSet<>(wordList);
    if (!words.contains(endWord)) return 0;
    Set<String> front = new HashSet<>(List.of(beginWord)), back = new HashSet<>(List.of(endWord));
    words.remove(beginWord);
    words.remove(endWord);
    int length = 1;
    while (!front.isEmpty() && !back.isEmpty()) {
        if (front.size() > back.size()) { Set<String> t = front; front = back; back = t; }
        Set<String> next = new HashSet<>();
        for (String cur : front) {
            char[] c = cur.toCharArray();
            for (int i = 0; i < c.length; i++) {
                char old = c[i];
                for (char ch = 'a'; ch <= 'z'; ch++) {
                    c[i] = ch;
                    String nb = new String(c);
                    if (back.contains(nb)) return length + 1;
                    if (words.remove(nb)) next.add(nb);
                }
                c[i] = old;
            }
        }
        front = next;
        length++;
    }
    return 0;
}
```

| Approach | Time | Space |
|---|---|---|
| BFS | O(26 · L² · N) | O(N · L) |
| Bidirectional BFS | O(26 · L² · N) worst | O(N · L) |

## Recall before you reveal
<details><summary>Why count words rather than steps?</summary>

The problem asks for the sequence length, one more than the number of changes.

</details>


<details><summary>Why remove words as you visit?</summary>

Removing from the set doubles as the visited array.
