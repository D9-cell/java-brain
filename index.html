Java Brain

Connect your profiles and sync the problems you already solved

One-click sync. Drag these two buttons onto your bookmarks bar once (show it with Ctrl+Shift+B): ⟳ Java Brain · LeetCode ⟳ Java Brain · GfG

  1. Open leetcode.com while logged in and click ⟳ Java Brain · LeetCode. You come straight back here with every problem you have solved ticked (your full history).
  2. Do the same on geeksforgeeks.org with ⟳ Java Brain · GfG.

The bookmarks only read your own solved list on those sites and pass it back in the link. Nothing is uploaded anywhere: usernames, ticks and synced lists stay in this browser. CodeChef does not publish solved problems, so tick those by hand. Re-run a bookmark whenever you solve more.
